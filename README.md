# Линка.Пузырик

Небольшое Windows-приложение: показывает приблизительное положение взгляда в пузырьке поверх обычных окон. Не нажимает, не прокручивает и не записывает историю взгляда.

## Запуск для проверки

Нужны Windows 10/11 x64, .NET Framework 4.8, Tobii Eye Tracker 4C или 5 и фирменное ПО Tobii с выполненной калибровкой. Совместимость Eye Tracker 5 со старым Tobii Interaction SDK **пока не подтверждена на устройстве**.

В Visual Studio откройте `Bubble/Bubble.csproj` (платформа **x64**) либо выполните:

```powershell
dotnet restore Bubble/Bubble.csproj -p:Platform=x64
dotnet build Bubble/Bubble.csproj -c Release -p:Platform=x64
dotnet run --project Checks/Checks.csproj -c Release
```

Сборка также выполняется установленным .NET SDK на macOS, но запуск Windows-приложения и испытание трекера возможны только на Windows. Для установки запустите `Linka.Bubble.Setup.exe` — файл доступен среди артефактов Windows CI либо собирается после проекта командой `makensis "-DSOURCE_ROOT=$PWD" Installer/Bubble.nsi` на macOS (на Windows передайте абсолютный путь к проекту). Установщик не требует прав администратора. Можно также запустить `Bubble/bin/x64/Release/net48/Linka.Bubble.exe` на Windows. Значок в системном трее открывает настройки, скрывает пузырёк и завершает приложение. Файлы настроек хранятся в `%LOCALAPPDATA%\LINKa\Bubble\settings.json`; координаты не сохраняются. При удалении приложения настройки сохраняются.

## Ограничения выпуска

Источником идеи для адаптера служит соседний `EyeLog`: `Host → EnableConnection → CreateGazePointDataStream().Next`. Его исходный код не копируется. `Tobii.Interaction` 0.7.3 снят с публичного списка NuGet и имеет отдельное лицензионное соглашение; право использования для этого проекта подтверждено владельцем проекта. Работа обеих моделей на Windows ещё требует проверки. Оверлей рассчитан на обычные окна и полноэкранный браузер; экран блокировки, UAC и exclusive fullscreen не поддерживаются.

Для проверки на устройстве: калибруйте Tobii, откройте браузер, проверьте точку в центре и по углам при масштабе Windows 100/125/150/200%, щелчок по ссылке под пузырьком, потерю взгляда, отключение USB и восстановление связи. Долгое отсутствие данных вызывает автоматическую попытку переподключения; статус виден в трее.
